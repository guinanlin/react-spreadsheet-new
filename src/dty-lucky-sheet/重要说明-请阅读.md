## ✨ 新功能

### 完整的 Canvas 渲染

`DtyLuckySheet.tsx` 现在包含：

1. **行列标题渲染**
   - 行号：1, 2, 3...
   - 列字母：A, B, C, D...

2. **单元格样式支持**
   - 背景色（`bg`）
   - 字体颜色（`fc`）
   - 加粗（`bl: 1`）

3. **数据自动转换**
   - celldata → data 矩阵
   - 自动填充空单元格

4. **API 接口**
   - getCellValue
   - setCellValue

## 📖 使用示例

```tsx
import { DtyLuckySheet } from '@/dty-lucky-sheet';

function App() {
  const [data, setData] = useState([
    {
      name: "Sheet1",
      id: "1",
      celldata: [
        { r: 0, c: 0, v: { v: "Hello", m: "Hello", bg: "#f0f0f0", bl: 1 } },
        { r: 0, c: 1, v: { v: "World", m: "World" } },
      ],
    },
  ]);

  return (
    <div style={{ width: "100%", height: "100vh" }}>
      <DtyLuckySheet data={data} onChange={setData} />
    </div>
  );
}
```

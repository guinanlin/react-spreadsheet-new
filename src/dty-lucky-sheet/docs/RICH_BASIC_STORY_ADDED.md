## 📖 样式属性说明

### 文字样式
- `bl: 1` - 粗体 (Bold)
- `it: 1` - 斜体 (Italic)
- `un: 1` - 下划线 (Underline)
- `cl: 1` - 删除线 (Strike through)

### 颜色
- `fc: "#ff0000"` - 文字颜色 (Font Color)
- `bg: "#ffff00"` - 背景颜色 (Background)

### 对齐
- `ht: 0/1/2` - 水平对齐（左/中/右）
- `vt: 0/1/2` - 垂直对齐（上/中/下）

### 字体
- `fs: 11` - 字体大小 (Font Size)
- `ff: "Arial"` - 字体系列 (Font Family)

### 格式化
- `ct: { fa: "$#,##0.00", t: "n" }` - 数字格式
- `m: "$1,234.56"` - 显示文本 (Masked)
- `v: 1234.56` - 原始值 (Value)

## 🎨 自定义你自己的样式

你可以基于 `cell-styled.ts` 创建自己的样式数据：

```typescript
{
  r: 0,  // 行号
  c: 0,  // 列号
  v: {
    v: "你的内容",        // 原始值
    m: "显示文本",        // 显示文本
    bg: "#4a86e8",       // 背景色
    fc: "#ffffff",       // 文字颜色
    bl: 1,               // 粗体
    it: 1,               // 斜体
    un: 1,               // 下划线
    fs: 14,              // 字体大小
    ht: 1,               // 居中对齐
    vt: 1,               // 垂直居中
  }
}
```

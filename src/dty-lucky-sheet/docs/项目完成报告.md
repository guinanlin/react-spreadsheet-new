## 🏗️ 架构决策

### 最初计划：三层架构

```
packages/
├── core/      # 核心逻辑层
├── react/     # React 组件层
└── formula/   # 公式引擎层
```

**问题**：
- ❌ Vite 无法加载内部包
- ❌ 动态导入失败
- ❌ 配置复杂
- ❌ 对当前阶段过度设计

### 最终方案：扁平化结构

```
components/
└── DtyLuckySheet.tsx  # 单文件组件
```

**优势**：
- ✅ Vite 完美兼容
- ✅ 代码集中，易于理解
- ✅ 修改即时生效
- ✅ 适合原型和演示

**trade-off**：
- 🟡 不适合超大型项目
- 🟡 功能扩展需要重构

**结论**：对于当前演示和学习目的，扁平化是**最佳选择**。

# Controlled Story 操作列使用指南

## 功能说明

在 `Controlled` Story 中添加了**操作列**，每一行都有增加和删除按钮。

## 如何访问

1. 启动 Storybook：
```bash
npm run storybook
```

2. 访问：`/story/spreadsheet--controlled`

## 功能详情

### 操作列位置
- 表格的**最后一列**
- 列标题显示：**"操作"**
- 该列为只读，不可编辑

### 两个操作按钮

#### ➕ 增加按钮（绿色）
- **功能**：在当前行的**下方**插入一行新数据
- **位置**：操作列的左侧
- **样式**：绿色边框和浅绿色背景

#### 🗑️ 删除按钮（红色）
- **功能**：删除当前行
- **位置**：操作列的右侧
- **样式**：红色边框和浅红色背景
- **限制**：至少保留一行（删除最后一行时会提示）

## 测试步骤

### 测试增加行
1. 点击第 1 行的 ➕ 按钮
2. 应该在第 1 行和第 2 行之间插入一行新数据
3. 打开浏览器控制台，应该看到：`执行添加行，行号: 0`
4. 新行的操作列应该自动包含两个按钮

### 测试删除行
1. 点击任意行的 🗑️ 按钮
2. 该行应该被删除
3. 打开浏览器控制台，应该看到：`执行删除行，行号: X`
4. 如果只剩一行，点击删除会弹出提示：`至少需要保留一行`

### 测试多次操作
1. 连续点击增加按钮，表格行数应该逐渐增加
2. 连续点击删除按钮，表格行数应该逐渐减少
3. 所有新增的行都应该包含操作列

## 调试方法

### 打开浏览器控制台
1. 按 F12 打开开发者工具
2. 切换到 Console 标签

### 观察日志输出
- 点击增加按钮时：`添加行，当前行: X` → `执行添加行，行号: X` → `新数据行数: Y`
- 点击删除按钮时：`删除行，当前行: X` → `执行删除行，行号: X` → `删除后行数: Y`

### 如果按钮没有反应
1. 检查控制台是否有 `添加行，当前行: X` 这样的日志
   - **有日志**：说明按钮点击事件触发了，但函数执行有问题
   - **无日志**：说明按钮点击事件被拦截或没有触发

2. 确认是否点击在按钮上
   - 按钮有绿色/红色的边框和背景
   - 鼠标悬停时应该显示提示文字

3. 尝试刷新页面
   - 有时候 Storybook 的热更新可能有问题

## 技术实现

### React Context 传递函数
```tsx
const RowActionsContext = React.createContext<{
  onAddRow: (row: number) => void;
  onDeleteRow: (row: number) => void;
} | null>(null);
```

### 自定义 DataViewer
每个操作列单元格使用自定义的 `ActionCellViewer` 组件：
```tsx
{
  value: '操作',
  readOnly: true,
  DataViewer: ActionCellViewer,
}
```

### 事件阻止冒泡
```tsx
onClick={handleAddRow}
onMouseDown={(e) => e.stopPropagation()}
```

## 常见问题

### Q: 点击按钮后没有反应？
A: 检查浏览器控制台是否有日志输出，确认点击是否被拦截。

### Q: 新增的行没有操作列？
A: 这个问题已经修复，所有新增的行都会自动包含操作列。

### Q: 删除最后一行时为什么不能删除？
A: 这是保护机制，至少需要保留一行数据。

### Q: 操作列能否移动到其他位置？
A: 可以，修改代码中插入操作列单元格的位置即可。

# CourseFlow 流程结构说明

## 🌳 树状层级结构

CourseFlow 组件采用**树状层级结构**，而非线性流程。整体结构如下：

```
课程开发 (Root)
    ├── 学习目标设定 (Stage 1)
    │   ├── 目标群体分析
    │   ├── 学习成果设定
    │   └── 评估标准定义
    │
    ├── 课程内容规划 (Stage 2)
    │   ├── 课程模块设计
    │   ├── 教学方法选择
    │   └── 教学时间安排
    │
    ├── 课程教学设计 (Stage 3)
    │   ├── 教学策略设计
    │   ├── 学习活动设计
    │   └── 教学评价方案设计
    │
    └── 课程资料制作 (Stage 4)
        ├── 教学PPT制作
        ├── 习题与案例设计
        └── 课件录制与编辑
```

---

## 📊 节点层级说明

### 三层结构

1. **第一层：根节点** - `课程开发`
   - ID: `root`
   - 类型: `mainNode`
   - 作用: 代表整个课程开发项目
   - 连接: 连接到4个阶段节点

2. **第二层：阶段节点** - 4个主要阶段
   - ID: `stage-1`, `stage-2`, `stage-3`, `stage-4`
   - 类型: `mainNode`
   - 作用: 代表课程开发的4个主要阶段
   - 连接: 从 root 连入，向子任务连出

3. **第三层：子任务节点** - 每个阶段3个子任务
   - ID: `1-1`, `1-2`, `1-3`, `2-1`, `2-2`, ...
   - 类型: `subNode`
   - 作用: 具体的执行任务
   - 连接: 从阶段节点连入

## 🎯 节点 ID 规范

### 命名规则

```typescript
// 根节点

// 阶段节点
id: 'stage-1'  // 第一阶段
id: 'stage-2'  // 第二阶段
id: 'stage-3'  // 第三阶段
id: 'stage-4'  // 第四阶段

// 子任务节点
id: '1-1'  // 第1阶段的第1个子任务
id: '1-2'  // 第1阶段的第2个子任务
id: '2-1'  // 第2阶段的第1个子任务
// ... 以此类推

// 占位符节点
id: 'placeholder-1'
id: 'placeholder-stage-2'
```

## 🔗 连接线（Edges）规范

### 连接规则

```typescript
// 根节点 -> 阶段节点（4条）
{ source: 'root', target: 'stage-1' }
{ source: 'root', target: 'stage-2' }
{ source: 'root', target: 'stage-3' }
{ source: 'root', target: 'stage-4' }

// 阶段节点 -> 子任务节点（每个阶段3条）
{ source: 'stage-1', target: '1-1' }
{ source: 'stage-1', target: '1-2' }
{ source: 'stage-1', target: '1-3' }

// ... 其他阶段同理
```

### 连接特性

- 从 root 到阶段的连接：`animated: true`（有流动动画）
- 从阶段到子任务的连接：`animated: false`（静态）
- 所有连接使用 `type: 'smoothstep'`（直角平滑）

### 连接线样式

- **主连接线**（root → stage）：
  - 颜色：灰色 `#94a3b8`
  - 宽度：2px

  - 类型：smoothstep（直角平滑）

  - 宽度：2px
  - 动画：无
  - 类型：smoothstep

## 💡 设计理念

### 为什么使用树状结构？

1. **层级清晰** - 一目了然的上下级关系
2. **并行展示** - 4个阶段可以同时进行
3. **易于扩展** - 每个阶段可独立添加子任务
4. **符合认知** - 与课程开发的实际工作方式匹配

### vs 链式结构

#### ❌ 链式结构（旧版）
```
阶段1 → 阶段2 → 阶段3 → 阶段4
```
- 暗示必须顺序执行
- 难以表示并行任务

#### ✅ 树状结构（新版）
```
         根
    ┌─┬──┼──┬─┐
    阶段1 阶段2 阶段3 阶段4
```
- 表示从整体出发，各阶段可并行
- 更灵活，更符合实际情况

## 🔧 自定义节点

### 添加新的阶段

```typescript
{
  id: 'stage-5',
  type: 'mainNode',
  data: {
    label: '课程评估与改进',
    type: 'main',
    status: 'pending',
    description: '课程上线后的持续优化'
  },
  position: { x: 850, y: 520 },
}

// 添加连接线
{ id: 'e-root-stage5', source: 'root', target: 'stage-5', animated: true, type: 'smoothstep' }
```

### 添加占位符

```typescript
{
  id: 'placeholder-new',
  type: 'placeholderNode',
  data: { label: '添加新阶段', type: 'main' },
  position: { x: 700, y: 220 },
}

// 连接到root
{ id: 'e-root-pnew', source: 'root', target: 'placeholder-new', animated: true, type: 'smoothstep' }
```

## 🎯 最佳实践

### 1. 布局建议

- 根节点居中偏上
- 阶段节点水平分布（前3个），第4个在下方
- 子任务紧贴阶段节点下方

### 2. 颜色使用

- 根节点：蓝色（in-progress）
- 已完成阶段：绿色（completed）
- 进行中阶段：蓝色（in-progress）
- 待处理阶段：灰色（pending）
- 被阻塞阶段：红色（blocked）

### 3. 交互提示

- 单击节点：查看详情
- 双击节点：编辑内容
- 拖拽节点：调整布局（editable模式）
- 点击占位符：添加新任务
